# Student Record Management System (SRMS)

## 1. Project Overview

The Student Record Management System is a Python application developed to manage student information. It allows users to register students, view records, search for students, update information, delete records, and count registered students.

## 2. Project Objectives

* To demonstrate object-oriented programming concepts.
* To manage student records efficiently.
* To demonstrate the use of Python lists.
* To implement instance methods and class methods.
* To store student records in a JSON file.
* To promote reusable, understandable, and maintainable code.

## 3. Technologies Used

* Python 3
* PyCharm IDE
* JSON for data storage
* Git and GitHub for version control and project sharing

## 4. System Features

1. Register a student.
2. Display all registered students.
3. Search for a student using a student ID.
4. Update student information.
5. Delete a student record.
6. Count registered students.
7. Save and load student records using JSON.

## 5. Object-Oriented Programming Concepts

### Classes and Objects

The Student class represents individual students. The StudentManagementSystem class manages student records.

### Encapsulation

Student information is organized within objects, while the management class provides methods for working with the records.

### Instance Methods

Instance methods perform operations such as registering, displaying, searching, updating, and deleting student records.

### Class Method

The get_system_name() method returns the name of the system.


## 6.How to Run the Program

1. Install Python 3.
2. Download or clone the project repository.
3. Open the project in PyCharm or another Python IDE.
4. Run main.py.
5. Follow the instructions displayed in the menu.

## 7.Privacy and Security

The application should store only information necessary for its intended purpose. Access to real student records should be restricted, and sensitive personal information should not be exposed in a public repository.
